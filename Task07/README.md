# Задание 07 — Сложные проценты

Программа позволяет вычислить сумму двумя способами:

- Будущая сумма: `A = P(1 + r/m)^(m*t)`
- Начальный капитал: `P = A / (1 + r/m)^(m*t)`

Здесь `r` вводится как годовая процентная ставка, `m` — число начислений в год, `t` — срок в годах. Запуск: `javac Main.java`, затем `java Main`; выберите 1 (расчёт будущей суммы) или 2 (расчёт начального капитала) и введите запрошенные значения.
