# Задание 11 — Сжатие повторяющихся строк

Запуск: `javac LineDeduplicator.java`, затем `java LineDeduplicator input.txt [compressed.txt] [restored.txt]`. Сжатый файл в кодировке UTF-8 начинается с `#removed=N`; далее каждая уникальная исходная строка записывается в порядке первого появления в формате `число<TAB>строка`. Метод `restore` восстанавливает повторы и исходный порядок, включая пустые строки. Число удалённых повторов выводится на экран и записывается в заголовок.
