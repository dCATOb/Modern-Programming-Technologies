# Задание 05 — Иерархия животных

Пакет `zoo` содержит абстрактный базовый класс `Animal`, абстрактные категории `Mammal` и `Bird`, а также конкретные классы `Lion` и `Parrot`. Пример демонстрирует переопределение методов и полиморфный вызов.

Из этой папки выполните: `javac zoo\*.java`, затем `java zoo.Main`.
