# Java — задания по программированию

В проекте собраны 16 самостоятельных заданий. Решение каждого находится в отдельной папке `Task01`–`Task16`. Примеры рассчитаны на JDK 17 или новее.

## Как запустить

Откройте папку нужного задания в терминале и выполните команды из README этой папки. Для обычных заданий это, как правило:

```bash
javac Main.java
java Main
```

У графических заданий Swing запускать программу следует в среде с графическим интерфейсом. В задании 05 исходники используют пакет `zoo`, а команды запуска указаны в его README.

Каждое задание можно открыть в IntelliJ IDEA, Eclipse или VS Code с установленными средствами разработки Java.

## Публикация на GitHub

Чтобы отправить проект на GitHub, войдите в свой аккаунт и создайте репозиторий. Затем укажите его адрес как удалённый репозиторий Git и отправьте туда файлы. Не размещайте в проекте пароли, токены и другие секретные данные.
