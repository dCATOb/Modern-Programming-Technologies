# Задание 13 — Текстовый редактор

Запуск: `javac TextEditor.java`, затем `java TextEditor`. В меню «Файл» доступны команды «Открыть», «Сохранить», «Сохранить как» и «Выход». Файлы читаются и записываются в кодировке UTF-8. Перед закрытием программа предлагает подтвердить отказ от сохранения несохранённых изменений.
