# Задание 14 — Просмотр дерева XML

Запуск: `javac XmlTreeViewer.java`, затем `java XmlTreeViewer`. Выберите XML-файл: компонент JTree покажет имена тегов элементов без атрибутов. Элементы с атрибутами пропускаются, но их потомки продолжают обрабатываться. Используется DOM-парсер JDK с запретом DTD и внешних сущностей.
