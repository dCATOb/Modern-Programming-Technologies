# Задание 06 — Калькулятор четырёх действий

Программа считывает выражение с пробелами в формате `число оператор число`, поддерживает `+`, `-`, `*`, `/` и десятичные числа. Деление на ноль и некорректный ввод сопровождаются сообщением об ошибке.

Запуск: `javac Main.java`, затем `java Main`; например, введите `2 * 6.5`.
