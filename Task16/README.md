# Задание 16 — Текстовый редактор с автокоррекцией

Запуск: `javac AutoCorrectEditor.java`, затем `java AutoCorrectEditor`. Это самостоятельная версия редактора из задания 13 с фоновой обработкой, запускаемой при вводе пробела и каждые три секунды. Исправляются примеры опечаток (`превет`, `спосибо`, `севодня`); добавьте записи в таблицу `corrections`, чтобы расширить словарь. Только поток обработки событий Swing читает и изменяет текст редактора. При закрытии окна фоновый поток останавливается.
