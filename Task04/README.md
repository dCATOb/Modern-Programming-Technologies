# Задание 04 — Композиция и агрегация

`Car` самостоятельно создаёт и содержит `Engine` (композиция: сильное владение и общий жизненный цикл). `Team` получает уже созданный `Player` и хранит ссылку на него (агрегация: игрок независим и может использоваться совместно с другими объектами или пережить команду).

Запуск: `javac Main.java`, затем `java Main` (для `List.copyOf` требуется Java 10 или новее).
